# R7 repository context: Portfolio

A 2017 PHP portfolio site with Home, About, Projects, Resume, and Contact pages.

- `Portfolio/index.php`, `about.php`, `projects.php`, `resume.php`, `contact.php`: page content.
- `Portfolio/inc/nav.php` and `footer.php`: shared navigation and footer included by the pages.
- `Portfolio/lib/css/styles.css`: styling; `Portfolio/lib/img/` stores page imagery.
- `Portfolio/lib/js/formSubmit.js`: contact form client-side behavior. Inspect `contact.php` before assuming server-side delivery works.

See [decisions](decisions.md) and [2017 changes](changes/2017-10.md). These notes describe the committed default branch, not whether the old external project links remain live.
